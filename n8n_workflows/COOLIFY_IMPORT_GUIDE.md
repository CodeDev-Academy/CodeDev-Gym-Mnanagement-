# Coolify n8n Workflow Import Guide

All 5 automated gym workflows have been packaged into a single master JSON file:
📂 **[`n8n_workflows/coolify_master_n8n_workflows.json`](./coolify_master_n8n_workflows.json)**

---

## 1. What Workflows Are Included?

1. **Direct WhatsApp Welcome & Digital Receipt**
   - **Type:** Webhook (`POST /webhook/send-welcome-receipt`)
   - **Purpose:** Automatically receives the member receipt from the Assign Plan modal and dispatches it directly to the member's WhatsApp number in the background without needing WhatsApp Web.
2. **Daily Executive Owner Summary (7:00 AM WAT)**
   - **Type:** Cron (`0 7 * * *`)
   - **Purpose:** Daily brief sent to the Gym Owner with yesterday's revenue, active athlete attendance, new members, and expired plans.
3. **3-Day Expiry Warnings**
   - **Type:** Cron (`0 8 * * *`)
   - **Purpose:** Proactively warns members 3 days before their plan expires so they can renew early.
4. **14-Day Inactivity Rescue**
   - **Type:** Cron (`0 10 * * 1,4`)
   - **Purpose:** Checks in on members who haven't scanned into the gym for 14 days.
5. **Lapsed Member Win-Back Pipeline (7d, 30d, 60d)**
   - **Type:** Cron (`0 11 * * *`)
   - **Purpose:** Follows up with lapsed members to bring them back.

---

## 2. How to Import Into Your Coolify n8n Instance

1. Log in to your **n8n** dashboard on Coolify.
2. In the left sidebar, click **Workflows** ➔ **Add Workflow** (or the **`...`** menu in top right).
3. Select **Import from File**.
4. Choose **`coolify_master_n8n_workflows.json`** (or individual JSON files from `n8n_workflows/`).
5. All 5 workflows will be imported into your canvas.

## 3. Recommended n8n Environment Variables

Under your n8n Service Settings in Coolify, add these environment variables:

| Variable | Example Value | Description |
| :--- | :--- | :--- |
| `API_BASE_URL` | `https://api.yourgym.com` | Your deployed Django backend API URL. |
| `API_TOKEN` | `gym_automation_bot_...` | The 40-character DRF token generated by `setup_automation_bot`. |
| `OWNER_WHATSAPP_NUMBER` | `+2349038446407` | Gym Owner's phone for executive alerts. |
| `WHATSAPP_API_KEY` | `your-meta-or-infobip-key` | Your WhatsApp Business / Infobip / Twilio Cloud API key. |
| `WHATSAPP_SENDER_NUMBER` | `447860099299` | Your verified business WhatsApp sender number. |
