# System & Workspace Rules

## Strict Instruction Following
- **Do not ever go beyond what the user has explicitly instructed.**
- Execute only the exact task given by the user.
- If you have any suggestions, improvements, or recommendations, present them to the user first and wait for explicit permission before taking any action.

## Automatic Version Control Commits
- **Always automatically commit and push:** At the completion of every step, stage, or feature implementation, automatically stage, commit with a clear descriptive message, and push all changes to GitHub (`git add .`, `git commit -m "..."`, `git push origin main`) so every single change is permanently recorded.
